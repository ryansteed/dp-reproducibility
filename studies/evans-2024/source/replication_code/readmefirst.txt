This contains the data and stata code to replicate the results in 

William N. Evans, Kathryn Muchnick, Olivia Rosenlund. 2024.  Virtual learning 
in kindergarten through grade 12 during the COVID-19 pandemic and chronic absenteeism. 
JAMA Netw Open. 7(8):e2429569. doi:10.1001/jamanetworkopen.2024.29569

Download this folder, change the directory to this folder, then execute the stata
program replication_code_program_1.do

This will use a number of program to produce a data set, then call
all_results_in_paper_1.do that will produce all the statistics in the
paper and the supplemental appendix.

If you want to skip producing all the data and onlyn look at the code 
that produces the results, you can just run all_results_in_paper_1.do.

Most of the files in the parent directory are stata data sets created 
during the construction of the data.  They are documented in the 
individual do files.  

We've included the log file for this master program and it contains all 
the results in the paper.
