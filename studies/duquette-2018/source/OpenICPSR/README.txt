Code for this project is written in Stata ".do" scripting language. See the "do" folder.

The file "master.do" will replicate included tables and figures. Before it can run, you must change a string indicated in the file to the pathway on your computer, or you will get missing file errors.

Some portions of the data and code for this paper are restricted to server-side use at the National Bureau of Economic Research (NBER). Those data and the relevant code are not included in this replication archive. Please contact me with any questions.

Selected inequality data are included by kind permission of Mark Frank, Thomas Piketty, Emmanuel Saez and Gabriel Zucman. See the data appendix for source and construction of all data series.
