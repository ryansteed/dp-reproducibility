README

The .do file "AERA OPEN PROGRAM TABLES FIGURES" generates all tables and figures in the published paper "Schooling During the Great Recession: Patterns of School Spending and Student Achievement using Population Data", available here https://journals.sagepub.com/doi/10.1177/2332858419877431

The program is organized to generate the tables and figures with appropriates notes and comments. Questions can be addressed to Kenneth Shores kshores@udel.edu 

Path directories are established in the first few lines of the program; those should be adjusted to the user's computer. The remainder of the program should work once appropriate packages are installed. If the user wishes to replicate tables and figures without outsheeting the results to Microsoft Word or Excel, they can just run the estimation routines and evaluate the output directly in Stata.
