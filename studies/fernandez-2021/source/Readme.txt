The calculations were made using STATA 13.1

outreg.ado is used to make the tables.

The aamc_data dataset contains the data from the AAMC report on residents
The oes_2000_2019_modified dataset contains May 2000-2019 State Occupational Employment and Wage Estimates.  
You can obtain more up to date data from https://www.bls.gov/oes/current/oessrcst.htm.
The pr_county_estab dataset is the county level establishment counts for physician offices from the Quarterly Census of Employment and Wages.
You can obtain more up to date data from https://www.bls.gov/cew/

You can replicate the results from Table 2 in the paper by running the AEA_PP_do_file.do in STATA.
