The following files are included in this packet:
1. analysis.do - this do file will create latex output tables corresponding to the table number in the paper.
2. militarization.dta is the main dataset
3. categories.dta is a collapsed dataset containing the names, quantities and values of items donated via the 1033 Program. It is called in analysis.do to replicate TableA1, which can then be viewed as a log file.
4. police.dta contains data on police agencies. It is called in analysis.do to replicate Table 4.
5. Militarization.tex - can be used to view all the latex output tables and figures.

INSTRUCTIONS:
Unzip all files in the same folder. Insert the path in the beginning of the do-file analysis.do. You can view all the output by compiling Militarization.tex
Table A1 can be viewed separately as a log file named TableA1.
